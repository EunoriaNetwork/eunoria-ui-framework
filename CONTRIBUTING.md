# Contributing

Thank you for your interest in contributing to the Eunoria UI Framework.

## How to contribute

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-change`.
3. Make your changes, keeping the `eu-` prefix and the existing style.
4. Test the example page (`index.html`) in a browser at 640x480 and above.
5. Commit with a clear message.
6. Open a Pull Request against `main`.

## Rules

- All code, comments and documentation must be in English.
- Do not change the visual identity (black base `#050505`, amber accent `#f5a623`) without discussion.
- Keep the framework dependency-free (no build step, no npm).
- Responsive support down to 640x480 is mandatory.
